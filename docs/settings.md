# 通用设置与数据存储

## 通用设置

配置页分成六组：通用、玩家数据查询、服务器状态、Boss 刷率、Atlas 查询与限额、玩家周报。保存后重载生效。

- **命令写法**：`@机器人 tarkov` 或 `/tarkov`，只影响帮助和回复里怎么显示命令。两种写法都能用；在 QQ 官方平台，`@机器人 /tarkov …` 也一直能用。
- **QQ 官方机器人单词命令**：QQ 官方机器人的命令里不能有空格，所以另有一组单词命令：`tpvp`、`tpve`、`tseason`、`tarena`（查玩家）、`tbind`、`tunbind`、`thelp`（绑定、解绑、帮助）、`tstatus`、`tboss`、`tmatch`（状态、Boss、匹配时间）、`tweekly`（玩家周报）。后面的参数可以带空格，例如 `@机器人 tpve 昵称`。把它们加进 QQ 机器人后台的命令列表即可；只对 QQ 官方平台生效。
- **谁可以使用**：所有人、仅管理员，或管理员和指定用户。“管理员”指 AstrBot 管理员，不是 QQ 群管理员。
- **指定用户 / 限定聊天**：填写平台用户 ID（例如 QQ 号）和 AstrBot 会话标识（聊天中发送 `/sid` 查看），留空不限制聊天。手工编辑配置文件时应为列表；写成其他类型时拒绝所有人。
- **访问数据接口时使用代理 / 代理地址**：开启后访问 tarkov.dev 和 Atlas 的请求都经过这个 HTTP/HTTPS 代理（不支持 SOCKS，需写明端口），不使用 AstrBot 或系统的代理设置；代理连不上时不会改为直连。部分服务器的 IP 会被 Cloudflare 拦截，查询提示“HTTP 403”时可以开启。

各功能自己的设置见对应文档：[玩家数据查询](player-query.md#设置)、[状态与 Boss](status-and-boss.md)、[匹配时间](matching.md#设置)、[玩家周报](weekly-report.md#设置)。

## 图片与字体

所有查询结果都是图片，用开源字体在本地绘制，不经过在线渲染服务；提示和出错信息是文字。图片统一使用完整中文字体，首次生成前下载约 17 MB，之后复用本地文件；下载失败会提示，可在设置中填写镜像地址。

## 数据存储

数据位于 `data/plugin_data/astrbot_tarkov_datasearch/`，具体文件见功能文档的“数据存储”一节：[玩家功能](player-query.md#数据存储玩家功能)、[状态与 Boss](status-and-boss.md#数据存储状态与-boss)、[玩家周报](weekly-report.md#数据存储)；匹配时间只保存在内存里。

- 绑定只保存带密钥的哈希，不保存 QQ 号等原始 ID。
- 用过本插件命令的群会话（只存会话标识，不存用户）会被记住，作为没填推送目标时状态和 Boss 变化的推送对象；周报播报只发给有周报名单的聊天。
- 插件不另存“谁查询了谁”，但 AstrBot 的日志会记下每条消息的发送者和内容，请像对待聊天记录一样保管日志和整个数据目录。
