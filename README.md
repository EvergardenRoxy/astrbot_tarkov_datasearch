# 塔科夫玩家数据查询

在 AstrBot 聊天中查询《逃离塔科夫》玩家的档案：等级、阵营、PMC 与 Scav 的战局数、存活率、K/D 和技能等级。按“模式 + 昵称”或“模式 + 账号 ID”查询，支持 PVP、PVE 和 PVP 赛季三种模式。

数据来自 [tarkov.dev](https://tarkov.dev) 公开的玩家档案快照（`players.tarkov.dev`）。插件不登录任何游戏账号，也不需要任何凭证。

## 功能

- 按昵称或账号 ID 查询玩家档案，可以指定模式，也可以使用配置里的默认模式。
- 显示内容：
  - 阵营、等级、声望、账号总游戏时长、成就数、最近活跃时间；
  - PMC 与 Scav 的战局数、存活数、存活率、击杀、死亡、K/D、击杀 PMC 数、撤离状态和最长连续存活；
  - 精英技能和等级最高的若干项技能。
- 显示档案的更新时间，超过 30 天没有更新时会注明；按昵称查到的档案昵称与名单不一致时会提示可能改过名。
- 输出纯文字，适合在聊天中阅读。生成图片的方式留待以后。
- 支持所有人、仅管理员、管理员和指定用户三种调用权限，也可以只允许在指定的聊天中使用。

## 安装与配置

需要 **AstrBot ≥ 4.16.0**。

1. 将本插件安装到 AstrBot 的插件目录，或使用插件管理页导入发行压缩包。
2. 在 AstrBot 使用的 Python 环境安装依赖：`pip install -r requirements.txt`（`aiohttp` 和 `yarl`，AstrBot 本身都已带）。
3. 按需修改默认模式、谁可以使用等设置，保存后生效。默认所有人都可以查询。

## 开始使用

```text
/tarkov pve Some_Player
/tarkov pvp 1234567
/tarkov 赛季 某个昵称
/tarkov 某个昵称            （使用默认模式）
/塔科夫 pve 1234567         （/塔科夫 与 /tarkov 相同）
/tarkov                    （显示用法）
```

- **模式**：`pvp`（也可写 `regular`、`常规`、`普通`）、`pve`、`赛季`（也可写 `season`、`pvp-season`），不区分大小写。
- **昵称**：字母、数字、下划线和连字符，3～24 个字符（系统生成的 `TarkovCitizen数字` 这类名字超过 15 个字符），不区分大小写。玩家名字恰好是 `help`、`pvp`、`pve`、`season` 等模式词时，要写上模式，例如 `/tarkov pvp season`。
- **账号 ID**：纯数字。如果某个 ID 没有档案，而这串数字也符合昵称规则，插件会再按昵称查一次。

回复示例（玩家名和账号 ID 为虚构）：

```text
【塔科夫 PVE 档案】Test_Player（账号 ID 1234567）
阵营 USEC｜等级 66
账号总游戏时长 1305 小时｜成就 52 个
最近活跃 2026-10-04 19:23

PMC：战局 1472，存活 1234，存活率 83.8%
　击杀 12115，死亡 164，K/D 73.87，击杀 PMC 1894
　阵亡 155，失踪 1，Run Through 27，转图 55，最长连续存活 60 局
Scav：战局 58，存活 42，存活率 72.4%
　击杀 110，死亡 15，K/D 7.33，击杀 PMC 66
　阵亡 15，Run Through 1，最长连续存活 8 局
精英技能（10 项）：耐力、力量、代谢、感知、专注、突击步枪、瞄准训练、搜索、工艺、藏身处管理
其他技能（前 10 项）：魅力 48、手术 42、投掷物 41、弹匣训练 40、健康 39、抗压 38、活力 29、栓动式步枪 24、精确射手步枪 22、霰弹枪 16

数据来自 tarkov.dev，档案更新于 2026-10-13 22:53（北京时间）
```

数字的含义：

- **K/D** = 击杀 ÷ 死亡。这里的击杀包括 AI，与游戏内统计页相同。PVE 模式下的“击杀 PMC”是 AI PMC。
- **存活率** = 存活 ÷ 战局数。
- **账号总游戏时长**不是单个模式的时长：一份真实的赛季档案只有 90 局，显示的却是 7141 小时。
- **等级**由总经验按 tarkov.dev 的等级经验表换算。
- **技能等级**是进度除以 100，满 51 级为精英。

## 数据从哪里来，有什么限制

插件只访问 `https://players.tarkov.dev`，这是 tarkov.dev 存放玩家档案快照的地方：

- `{模式}/index.json`：昵称名单，tarkov.dev 每天更新一次，插件默认每周检查一次。PVP 名单约 300 万名玩家，压缩后约 30 MB。
- `{模式}/{账号ID}.json`：单个玩家的档案。

由此带来的限制：

- **只有在 tarkov.dev 被查询过的玩家才有档案。** 档案也不是实时的，是 tarkov.dev 上次查询这个玩家时保存的快照。回复中会写明更新时间，超过 30 天会注明（可能是玩家很久没玩这个模式，也可能是很久没人查询过他）。实测在 tarkov.dev 网站查看一次玩家后，这里的档案随即更新。
- **按昵称查询依赖昵称名单，可能查不到或查到旧名字。** 例如刚改名的玩家、最近才第一次被查询的玩家（插件默认每周更新一次名单）。**用账号 ID 查询最准确。** 账号 ID 可以在 tarkov.dev 玩家页面的网址中找到（`tarkov.dev/players/模式/账号ID`）。
- **部分服务器的 IP 会被 Cloudflare 拦截。** 查询时会提示“HTTP 403，Cloudflare 拦截”，可以在配置中开启代理。
- tarkov.dev 网站的实时查询接口（`player.tarkov.dev`）需要浏览器完成 Cloudflare 人机验证，机器人无法使用。插件不使用这个接口，也不会尝试绕过人机验证或访问频率限制。

## 常用设置

- **默认模式**：命令里没写模式时使用，默认 PVP。
- **谁可以使用**：所有人（默认）、仅管理员，或管理员和指定用户。“管理员”指 AstrBot 管理员，不是 QQ 群管理员。
- **指定用户**：填写平台用户 ID（例如 QQ 号），只在“管理员和指定用户”模式下生效。
- **限定聊天**：只允许在这些聊天中使用，留空不限制。填写 AstrBot 会话标识（在聊天中发送 `/sid` 查看），必须与会话标识完全相同（首尾空格和空行会被忽略）。手工编辑配置文件时，这一项和“指定用户”应是列表；写成一个字符串时按一项处理，写成其他类型时拒绝所有人。
- **显示的技能数**：精英技能总是全部列出，这里设置其余技能显示几项，默认 10，设为 0 不显示技能。
- **档案缓存时间**：同一个玩家在这段时间内再次查询时不再访问 tarkov.dev，默认 10 分钟，只保存在内存中。
- **昵称名单更新间隔**：默认 168 小时（每周一次）。tarkov.dev 每天重建名单，所以每次检查通常都要重新下载（PVP 约 30 MB，加上约 25 秒整理）；只有间隔短于一天时，才常遇到名单没变、只做一次很小请求的情况。下载失败后 10 分钟内不会再试，这期间按昵称查询会提示稍后再试，按账号 ID 查询不受影响。
- **下载最长等待**：下载名单最多等多久，默认 120 秒。查询单个档案最多等 60 秒。
- **访问 tarkov.dev 时使用代理 / 代理地址**：默认关闭。开启后插件的所有请求都经过这个 HTTP/HTTPS 代理（不支持 SOCKS），不使用 AstrBot 或系统的代理设置；代理连不上时不会改为直连，开启后没有填写地址时查询会报错。代理地址必须写明端口。

## 数据存储

数据位于 `data/plugin_data/astrbot_tarkov_datasearch/`：

- `names-profile.sqlite3`、`names-pve.sqlite3`、`names-pvp-season.sqlite3`：各模式的昵称名单，分别在第一次按昵称查询该模式时生成。PVP 名单约 100 MB，PVE 约 4 MB，赛季约 1.5 MB。可以随时删除，下次查询时会重新下载。
- 玩家档案只缓存在内存中，不写入磁盘。插件自己不另存查询记录；但 AstrBot 的日志会记下每条消息的发送者和内容（包括 `/tarkov` 命令），插件日志里也有被查询的昵称或 ID，请像对待聊天记录一样保管日志。

第一次按昵称查询 PVP 玩家时，插件要下载约 30 MB 的名单并整理成数据库。实测需要约 30 秒，期间内存峰值约 100 MB，插件会先提示“正在更新玩家名单”。
